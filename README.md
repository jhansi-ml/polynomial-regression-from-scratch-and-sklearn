# polynomial-regression-from-scratch-and-sklearn
Polynomial Regression implemented from scratch using NumPy and compared with sklearn.

## Features
• Polynomial feature creation
• Gradient Descent optimization
• Loss calculation
• Comparison with sklearn
• Visualization of polynomial curves

## Technologies Used
Python
NumPy
Pandas
Matplotlib
Scikit-learn

## Output
Polynomial curve fitting the dataset.

## Learning Outcome
Understanding how polynomial regression works internally.
